# TTS 캐릭터별 보이스 프리셋 아이디어

작성일: 2026-06-10

## 배경

TTS 생성 결과를 검수해보니 완벽하지는 않지만, 인물 대사에서 말투나 연기톤이 조금씩 달라지는 느낌이 있었다. 이를 앱 기능으로 확장하면 그림책 영상의 낭독 품질을 올릴 수 있다.

현재 TTS 앱은 에피소드 대본을 페이지별 텍스트로 읽고, 전체 대본에 하나의 TTS 설정을 적용하는 구조다. 다음 단계로는 페이지 안의 문장을 발화 단위로 나누고, 각 발화에 화자와 캐릭터 프리셋을 연결하는 방식을 고려한다.

## 핵심 아이디어

- 대본에서 캐릭터별 대사를 구분한다.
- 각 캐릭터에 기본 보이스, 연기톤, 말속도, 감정 지시를 미리 지정한다.
- 음성 생성 시 발화별로 해당 캐릭터 프리셋을 적용한다.
- 가능하면 앱 화면에서 줄마다 화자를 선택하는 방식으로 시작한다.

## 추천 방향

초기 구현은 자동 추정보다는 수동 선택 중심이 좋다.

앱에서 대본을 불러오면 페이지별 텍스트를 발화 단위로 보여주고, 각 줄 옆에서 `나레이터`, `루루`, `포포`, `선생님` 같은 화자를 선택한다. 선택된 화자에 따라 저장된 프리셋이 적용되어 검수용 음성이나 최종 영상용 음성이 생성된다.

자동 화자 추정은 나중에 보조 기능으로 추가한다. 예를 들어 `"..." 루루가 말했다` 같은 문맥을 읽어 첫 할당을 제안하되, 최종 결정은 사용자가 검수 화면에서 고치는 흐름이 안전하다.

## 예시 데이터 구조

```yaml
characters:
  narrator:
    label: 나레이터
    voice: Kore
    style: 따뜻하고 차분한 그림책 낭독
  lulu:
    label: 루루
    voice: Aoede
    style: 어린아이처럼 조심스럽지만 밝은 톤
  popo:
    label: 포포
    voice: Puck
    style: 졸리고 느긋한 장난꾸러기 톤

pages:
  - page: "01"
    lines:
      - speaker: narrator
        text: 루루는 문 앞에서 조심스럽게 말했어요.
      - speaker: lulu
        text: 나 약속 지킬게.
```

## 앱 흐름 초안

1. 에피소드를 선택한다.
2. TTS 대본을 불러온다.
3. 페이지별 텍스트를 발화 단위로 나눈다.
4. 각 발화 옆에서 캐릭터를 선택한다.
5. 캐릭터별 보이스와 연기톤 프리셋을 적용해 검수용 음성을 생성한다.
6. 문제가 있는 줄만 화자, 보이스, 지시문을 수정해 다시 생성한다.
7. 최종 음성을 페이지별로 합쳐 기존 영상 생성 파이프라인에 넘긴다.

## 구현 단계 후보

### 1단계: 캐릭터 프리셋 파일

시리즈별로 캐릭터 보이스 설정 파일을 둔다. 예를 들어 산호마을 어린이집 시리즈에는 루루, 포포, 토리, 아루, 수아, 선생님, 나레이터 기본값을 저장한다.

### 2단계: 발화 단위 편집 UI

기존 페이지별 textarea를 유지하되, 추가 모드로 발화 단위 편집 화면을 제공한다. 각 줄에 캐릭터 선택 드롭다운을 붙인다.

### 3단계: 발화별 TTS 생성

하나의 페이지 안에서도 발화별로 다른 보이스를 사용해 mp3를 만들고, 순서대로 이어 붙여 페이지 오디오를 만든다.

### 4단계: 자동 화자 제안

대본 문맥에서 화자를 추정해 기본값을 채운다. 단, 자동 추정 결과는 반드시 사용자가 검수하고 수정할 수 있어야 한다.

## 주의할 점

- 발화가 너무 잘게 쪼개지면 생성 파일과 검수 작업이 많아진다.
- 모델별로 보이스와 스타일 지시 지원 정도가 다를 수 있다.
- 캐릭터별 보이스가 많아지면 시리즈 톤이 산만해질 수 있으므로 기본 프리셋은 적게 시작한다.
- 나레이터와 캐릭터 대사의 볼륨, 속도, 쉼 길이가 자연스럽게 이어지는지 검수해야 한다.

## 다음에 정할 것

- 화자 정보는 대본 파일에 직접 표기할지, 앱 화면에서만 저장할지
- 캐릭터 프리셋 파일 위치를 시리즈 문서 아래에 둘지, TTS 앱 설정 아래에 둘지
- Gemini TTS와 Cloud TTS 중 어느 쪽을 먼저 캐릭터별 보이스 대상으로 삼을지
- 검수용 음성을 페이지 단위로 만들지, 발화 단위로도 만들지
