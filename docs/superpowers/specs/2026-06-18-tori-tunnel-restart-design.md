# 토리야 한 걸음만 산호터널 재작업 설계

Date: 2026-06-18

## Goal

`토리야, 한 걸음만` 에피소드를 기존 실패 후보의 시각 오염 없이 다시 시작한다. 이번 재작업은 페이지 생성보다 먼저 산호터널을 고정 소품으로 잠그고, 그 잠금 기준을 통과한 뒤 표지와 본문 페이지를 작은 배치로 생성한다.

핵심 실패 원인은 산호터널이 페이지마다 다른 구조물로 변한 것이다. 이전 작업에서는 터널이 큰 동굴, L자 구조, 코너가 있는 통로, 같은 방향을 바라보는 두 입구, 너무 넓은 실내 복도처럼 바뀌었다. 새 작업은 이 변형을 막는 데 초점을 둔다.

- 첫 페이지 배치: 터널 잠금 승인 후 표지, 1페이지, 2페이지, 3페이지

## Tunnel Lock

산호터널은 한 번 정해진 소품으로 다룬다. 페이지마다 새로 해석하지 않는다.

필수 구조:

- 직선 단일축 통과 튜브
- 낮은 유아용 crawl-through 놀이기구
- 토리가 몸과 고개를 낮춰 지나갈 정도의 크기
- 파스텔 분홍과 산호빛의 부드러운 표면
- 두꺼운 둥근 테두리와 안전한 말랑한 형태
- 안쪽은 약간 어둑하지만 반대편 빛이 들어오는 따뜻한 분위기
- 조개나 바다유리 장식은 작고 부드럽게만 사용

금지 구조:

- L자 구조
- 코너가 있는 통로
- 옆 가지나 두 번째 터널
- 서로 같은 방향을 보는 두 입구
- 거대한 동굴이나 산호 바위굴
- 넓은 실내 복도 같은 터널 내부
- 토리의 크기가 장면마다 달라 보이게 만드는 스케일 변화

장면별 원칙:

- 둘 다 보여야 하는 페이지가 아니면 입구 하나만 보이게 한다.
- 두 끝을 모두 보일 때는 반드시 한 직선 튜브의 서로 반대쪽 끝으로 읽혀야 한다.
- 걱정 장면에서는 실제 터널 크기와 토리의 상상 속 걱정 이미지를 분리한다.
- 내부 장면에서도 터널은 낮고 좁은 유아용 통과 튜브로 유지한다.

## New Workflow

1. `rework_2026-06-18` 아래에 `episode_worklog.md`, `page_plan.md`, `tunnel_lock/tunnel_lock_prompt_plan.md`를 만든다.
2. 산호터널 잠금용 레퍼런스 보드를 만든다. 보드에는 공식 터널, 크기 비교, 토리 스케일, 금지 구조 예시 문장을 함께 둔다.
3. 산호터널 고정 후보를 먼저 생성한다.
4. 후보를 QA해서 `tunnel lock pass`가 나오기 전에는 페이지를 생성하지 않는다.
5. 터널 잠금이 통과하면 표지와 1-3페이지만 Batch 1로 생성한다.
6. 각 페이지는 생성 전 `References To Attach` 목록을 가진다.
7. 각 페이지는 QA 결과를 worklog에 기록하고, 사용자가 승인하기 전에는 `final`에 승격하지 않는다.
8. Batch 1 승인 후에만 Batch 2로 넘어간다.

## QA Gates

### Tunnel Geometry

- 하나의 직선 통과 튜브로 읽힌다.
- 같은 방향 입구 두 개가 보이지 않는다.
- 코너, 가지, 두 번째 터널이 없다.
- 토리와 비교했을 때 낮은 유아용 크기로 보인다.
- 실내 장면에서도 큰 복도나 동굴처럼 보이지 않는다.

### Character Identity

- 토리는 공식 레퍼런스의 초록 몸, 둥근 얼굴, 등껍질, 노란 모자, 세일러복 느낌을 유지한다.
- 놀이터 놀이 중에는 토리와 친구들이 가방을 메지 않는다.
- 방울이는 연한 하늘색 물방울 형태를 유지하고 유리구슬이나 해파리처럼 바뀌지 않는다.
- 마리 선생님은 노란 앞치마, 별 머리핀, 보라색 인어 꼬리, 어린이집 선생님 인상을 유지한다.
- 아루, 루루, 수아, 포포, 몽글이, 준이가 등장할 때는 각 공식 레퍼런스의 종과 고정 디테일을 유지한다.

### Story Logic

- 토리는 겁쟁이가 아니라 조심스러운 아이다.
- 친구나 선생님이 토리를 끌거나 밀거나 부끄럽게 만들지 않는다.
- 마리 선생님은 도전보다 감정 인정을 먼저 한다.
- 방울이는 토리보다 먼저 보여주는 안전한 안내자다.
- 성공 장면은 10페이지 전까지 미리 보여주지 않는다.

### Text

- 첫 페이지 생성부터 정확한 한국어 본문 텍스트를 포함한다.
- 텍스트가 틀렸지만 그림이 좋으면 그림 후보를 따로 보존하고 텍스트 패널 수정 대상으로 기록한다.
- 틀린 텍스트가 있는 후보는 `final`로 승격하지 않는다.

### Contamination

- 기존 실패 후보의 터널 구조를 따라가면 실패 처리한다.
- 기존 후보의 큰 동굴형 산호, L자 구조, 같은 방향 이중 입구, 넓은 내부 통로를 반복하지 않는다.
- 의미 없는 간판, pseudo-writing, random signage가 있으면 실패 또는 수정 대상으로 둔다.

## Output Rules

- 새 후보는 `rework_2026-06-18` 아래에 저장한다.
- 파일명은 날짜와 버전을 포함한다.
- 승인 전 후보 상태는 `candidate pass`, `hold`, `fail`, `superseded` 중 하나로 worklog에 기록한다.
- 사용자가 승인한 파일만 이후 새 `final` 승격 대상으로 삼는다.
- 기존 `final` 파일은 사용자가 명시적으로 승인하기 전까지 덮어쓰지 않는다.

## First Action
