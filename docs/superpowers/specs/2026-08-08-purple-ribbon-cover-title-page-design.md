# 《자줏빛 리본의 손님》 표지·속표지 설계

## 목적과 범위

- 누락된 별도 표지 `00_표지.png`와 내지 속표지 `01_페이지.png`를 제작한다.
- 승인된 본문 `02_페이지.png`~`04_페이지.png`와 5페이지 후보의 번호·내용은 바꾸지 않는다.
- 최종 인쇄 구조는 기존 `print_spread_plan.md`를 유지한다: 표지는 내지와 별도이며, 내지 1페이지가 오른쪽 속표지다.

## 00 표지

- 제목: `심해탐정 셜록 핀` / `자줏빛 리본의 손님`.
- 구도: 에메랄드빛 미역숲의 좁은 물길을 배경으로 셜록 핀과 모리가 서로 마주보는 라이벌 대치형 세로 표지.
- 셜록 핀은 왼쪽, 모리는 오른쪽에 두되 두 캐릭터가 비슷한 시각적 비중을 갖는다.
- 모리는 승인된 낮아진 포니테일 위치, 얇은 금빛 테두리의 자줏빛 리본, 짙은 남색 조끼, 검은 망토, 금빛 회중시계를 유지한다.
- 셜록 핀은 공식 캐릭터 시트의 얼굴·의상·인어 꼬리를 그대로 유지한다.
- 자줏빛 리본, 회중시계, 소용돌이 카드는 사건의 단서처럼 보이되 자모 해답 `미역숲`은 공개하지 않는다.
- 제목은 상단의 비교적 단순한 색면에 배치해 캐릭터 얼굴·리본·회중시계를 가리지 않는다.

## 01 속표지

- 조개빛 크림색 바탕과 넓은 여백을 사용한다.
- 중앙에 `심해탐정 셜록 핀`과 `자줏빛 리본의 손님`을 안동엄마까투리체로 정확히 조판한다.
- 작은 자줏빛 리본과 소용돌이 카드만 장식으로 사용하며 인물 전신이나 복잡한 배경은 넣지 않는다.
- 산호색과 청록색의 얇은 테두리 또는 작은 포인트를 사용해 승인된 본문 글 페이지와 연결한다.
- 속표지는 내지 1페이지 오른쪽 면이므로 왼쪽 책등 안전 여백을 충분히 확보한다.

## 공통 아트스타일

- 공식 캐릭터·미역숲·핵심 단서 레퍼런스를 시각적 기준으로 사용한다.
- 2D 애니메이션풍 선화, 큰 눈, 제한된 부드러운 명암, 깨끗한 회화적 마감을 유지한다.
- 3D 토이·클레이·픽사풍 부피감, 플라스틱 광택, 과도한 입체 음영을 금지한다.
- 화면 전체의 작은 금빛 점, 점묘, 잔기포, 잔자갈, 미세 잎맥, 반복 하이라이트를 억제한다.
- 넓고 매끈한 색면과 분명한 시선 중심을 우선하며 핵심 단서는 선명하게 유지한다.
- 일반 물고기에게 다리·발·신발을 붙이지 않는다.

## 제작과 승인 흐름

1. 표지 후보를 공식 셜록 핀·모리·미역숲·핵심 소품 레퍼런스로 제작한다.
2. 표지의 캐릭터 정체성, 제목 정확성, 단서 노출 수준, 미세 질감 억제를 검수한다.
3. 사용자 승인 후 `final/00_표지.png`로 승격한다.
4. 승인된 본문 글 페이지 배경 체계를 재사용해 속표지를 결정론적으로 조판한다.
5. 제목 철자, 안동엄마까투리체, 책등·재단 여백을 검수한다.
6. 사용자 승인 후 `final/01_페이지.png`로 승격한다.
7. 보류 중인 5페이지 글 후보 검토로 돌아간다.

## 완료 기준

- `00_표지.png`와 `01_페이지.png`가 모두 1054×1492 PNG 규격이다.
- 제목 `심해탐정 셜록 핀 / 자줏빛 리본의 손님`의 글자와 문장부호가 정확하다.
- 셜록 핀과 모리가 공식 시트와 같은 캐릭터로 읽힌다.
- 표지가 라이벌 대치와 미스터리를 전달하되 이야기의 해답을 직접 공개하지 않는다.
- 속표지가 본문 글 페이지와 같은 서체·여백·팔레트 체계를 갖는다.
- 두 페이지 모두 눈을 피로하게 하는 자글자글한 미세 질감이 억제되어 있다.
- 기존 `02~05` 본문 파일의 번호와 내용이 보존된다.
