# Coral Town Daycare no-bag character references

This folder contains indoor-use character reference sheets derived from the official character sheets.

## Purpose

Use these references for indoor daycare scenes where children should not wear school bags, especially:

- dining room / meal scenes
- classroom scenes
- nap, washroom, and indoor play scenes

Use the original `references/characters/*.png` files for scenes where bags are part of the story context, such as arrival, departure, outdoor movement, or personal belongings.

## Prompting Rule

When using these files, prefer a positive reference instruction:

```text
Use the no-bag indoor character reference sheet for each visible character.
Preserve the character shape, clothing, species anatomy, color, and expression.
```

Avoid repeatedly adding strong negative bag-removal language in page prompts. Strong no-bag wording can disturb character fidelity because bags are prominent in the original character sheets.

For Popo, do not add black dot eyes, pupils, anime eyes, or other explicit eye marks. Popo's base look is a nearly eyeless translucent moon jellyfish.
