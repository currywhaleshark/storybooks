## 시리즈 고정 규칙

- 3세 대상 밝고 따뜻한 어린이 그림책 스타일.
- 심해지만 무섭거나 어둡지 않음.
- 둥글고 귀여운 형태, 큰 눈, 부드러운 표정.
- 딥시티 팔레트와 맞는 깊은 파랑, 보라, 에메랄드, 핑크, 골드 포인트를 유지.
- 반짝이 자체의 발광은 금빛이 아니라 부드러운 푸른 생물발광.
- 기존 `초롱이` 초롱아귀처럼 보이면 안 됨. 낚싯대형 등불, 큰 입, 포식자 실루엣 금지.

## 캐릭터 잠금

- 이름: 반짝이
- 모티브: 바다반딧불이류 발광 오스트라코드
- 크기: 팝팝보다 훨씬 작은 친구, 손바닥 위 작은 빛방울 정도
- 형태: 투명한 조개껍질 같은 둥근 몸, 작고 귀여운 눈, 아주 작은 지느러미 또는 더듬이
- 발광: 몸 안쪽에서 은은한 푸른빛이 나고, 주변에 작은 푸른 빛방울이 톡톡 생김
- 성격: 조용하고 다정함, 음악 박자에 맞춰 반짝이며 대답함
- 용도: 회상 거품과 마지막 빛 편지 장면에서 알아볼 수 있어야 함

## 생성 프롬프트

Create an official character reference sheet for a new character in the bright warm Korean children's picture book series "Deep Sea Detective Sherlock Fin".

Character name: Ban-jjak-i, a tiny sea-firefly-inspired bioluminescent ostracod friend. Make the character small, round, gentle, and childlike, with a transparent shell-like body, cute eyes, tiny fins or soft antennae, and a soft blue bioluminescent glow from inside the body. Add small blue glowing bubbles or dots around the character to show it blinking to music rhythms.

The character must feel like a friendly tiny glowing companion for Popop the round yellow pufferfish, not like an anglerfish, not a predator, not scary, no lure rod, no large teeth, no dark horror mood. It should be visually distinct from any lanternfish/anglerfish character. Use the same polished warm children's book illustration style as the Sherlock Fin character sheets: rounded shapes, clean soft shading, expressive faces, cute safe proportions, bright deep-sea palette.

Reference sheet layout: one large front view, one small side view, three expression/action poses: happy blinking, quietly missing a friend, glowing in rhythm with music. Include simple color swatches for transparent pale aqua shell, soft cyan-blue glow, tiny warm cheek accent. Plain light background, no story text panel, no complex scene, no readable typography required.
