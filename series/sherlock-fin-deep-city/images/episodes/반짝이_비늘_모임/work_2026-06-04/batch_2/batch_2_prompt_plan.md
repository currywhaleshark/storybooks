## 04

### 장면

탐정 사무소에서 셜록 핀이 포리에게 묻고 수첩에 적는다. 포리 머리 위 회상 말풍선에는 타리가 진행하고 포리 혼자 반짝이 조개를 세거나 짧은 노래를 다시 부르는 모임 장면이 보인다. 회원이 포리 하나뿐이라는 점이 명확해야 한다. 텍스트 여백은 왼쪽 아래.

### Text

```
먼저 잘 들어 보자.

‘모임에서 무슨 일을 해?’

‘반짝이 비늘을 가진 친구만
들어올 수 있대요.

그런데 갈 때마다
회원은 저 하나뿐이에요.

하는 일은······
반짝이 조개를 세거나,
노래 한 곡 부르는 게 다예요.

가끔은 같은 노래를
한 번 더 부르기도 해요.’

‘어라?
조건은 까다로운데
하는 일은 너무 쉽네.

첫 번째 단서구나.’
```

## 05

### 장면

탐정 사무소 책상 탑뷰. 초대장, 반짝이 배지, 간식 꾸러미, 딥시티 지도, 물방울 시계 그림이 놓여 있고 셜록 핀이 돋보기로 초대장을 본다. 지도에는 포리 집과 먼 미역 숲 공터 사이가 점선으로 길게 표시된다. 텍스트 여백은 오른쪽 위.

### Text

```
이번에는 물건을 보자.

포리가 초대장을 내밀었어요.

초대장에는 이렇게 적혀 있었어요.

‘오늘도 같은 시간!
먼 미역 숲 공터에서!’

‘쉬운 일을 하는데
간식과 배지도 주고,

장소는 꼭 집에서 멀고,
시간은 꼭 같아.

두 번째 단서구나.’
```

## 06

### 장면

미역 숲 공터 모임. 셜록 핀이 미역 뒤에 숨어 몰래 살핀다. 타리는 친절하지만 어색하게 웃으며 물방울 시계를 자꾸 본다. 포리는 조개 세기를 끝내고 이제 끝났는지 묻는 표정. 장소는 급히 꾸민 듯 엉성하지만 무섭지 않다. 텍스트 여백은 아래쪽.

### Text

```
이번에는 잘 보자.

셜록 핀은 모임을
살짝 살펴보았어요.

모임 장소는 어쩐지 엉성했어요.
오늘은 미역 숲 공터였지요.

타리는 친절했지만
자꾸 물방울 시계를 보았어요.

포리가 물었어요.
‘이제 끝났나요?’

타리가 어색하게 웃었어요.

‘아직 반짝이 시간이
조금 남았어요!
노래를 한 번만 더 불러 볼까요?’

셜록 핀이 눈을 반짝였어요.

‘시간을 때우고 있어.
세 번째 단서구나.’
```

## 07

### 장면

탐정 사무소의 추리 칠판 정면. 칠판에는 세 단서가 간단한 그림 카드로 연결된다. 셜록 핀이 세 단서를 잇고, 머리 위 생각 거품에는 포리를 같은 시간 동안 집에서 멀리 두는 것이 진짜 목적이라는 깨달음이 그림으로 표현된다. 텍스트 여백은 위쪽.

### Text

```
셜록 핀은 단서를 하나로 모았어요.

조건은 까다로운데
회원은 포리뿐이에요.

일은 쉬운데
간식과 배지는 후해요.

매일 같은 시간,
집에서 먼 곳으로 불러요.

그리고 타리는
자꾸 시계를 봐요.

‘아, 그런 이유가 있었구나!

이 모임의 목적은
일을 시키는 게 아니야.

진짜 목적은 시간.

포리를 같은 시간 동안
집에서 멀리 두는 거야!

그럼 그 시간에
포리의 집에서
무슨 일이 일어날까?’
```
