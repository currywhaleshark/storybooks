- 캐릭터 정체성: 두두, 가비, 모래 말미잘이 서로 다른 실루엣으로 즉시 구분된다.
- 단서 가독성: 깊은 발자국과 얕은 발자국의 차이가 한눈에 보인다.
- 논리 보존: 목걸이가 깊이 변화 지점에 놓인다.
- 오염 방지: 이전 에피소드의 문틈, 사무소 물살, 음악 노트, 잘못된 물살 표현이 들어오지 않는다.

## 발자국 형태 수정 잠금 - 2026-06-30

- 사용자 수정: 새우 발자국은 단순한 불규칙 타원형 두 줄이 맞다.
- 기준: 각 길은 좌우 두 줄의 타원형 자국으로 이어진다. 타원은 크기, 간격, 각도가 조금씩 불규칙해 자연스럽게 보인다.
- 유지: 목걸이는 V자의 꼭짓점이고, 두 팔은 교차하지 않는다. 한쪽은 깊고 어둡게, 다른쪽은 얕고 밝게 처리한다.
- 금지: X자 교차, 게 발자국, 발바닥/동물 발자국, 쉼표형 다리 클러스터, 점무리, 집게/갈고리 자국.
