# 자줏빛 리본의 손님 — TTS 영상화 조정 계획

## 핵심 방식

- 실제 책 펼침처럼 `왼쪽 그림 페이지 + 오른쪽 글 페이지`를 가로로 이어 붙여 한 화면에 함께 보여준다.
- 기본 펼침 원본은 두 A5 페이지를 그대로 결합한 2108×1492 PNG로 만든다. 페이지 사이 추가 간격 없이 맞붙이고, 양쪽의 기존 안전 여백과 테두리를 유지한다.
- TTS는 화면 오른쪽 글 페이지의 원문을 읽는다. 글이 이미 화면에 있으므로 별도 자막은 기본적으로 넣지 않는다.
- 16:9 영상에서는 펼침 전체를 자르지 않고 가운데 맞춤으로 축소한 뒤 좌우에 조개빛 또는 짙은 청록색 여백을 둔다.
- 한 펼침 길이는 `TTS 실제 길이 + 시작 여유 0.6초 + 끝 여유 0.8초`를 기본으로 한다.
- 펼침 전체가 한눈에 읽혀야 하므로 페이지별 확대·패닝은 기본적으로 사용하지 않는다. 필요한 경우에도 좌우 페이지가 화면에서 잘리지 않는 범위만 허용한다.

## TTS·자막 잠금

- 낭독 원문은 홀수 글 페이지 03~29의 본문을 한 글자도 바꾸지 않고 사용한다.
- 따옴표 안 대사는 화자별 음색 또는 억양만 구분하고 문구는 바꾸지 않는다.
- 별도 자막은 기본적으로 끈다. 접근성 자막이 필요할 때만 영상 플레이어 자막 트랙으로 추가한다.
- 펼침 원본에는 페이지의 모든 요소를 그대로 보존하며 중앙 접합부를 자르거나 겹치지 않는다.
- 31페이지 카드는 `ㅁ, ㅣ / ㅇ, ㅕ, ㄱ / ㅅ, ㅜ, ㅍ` 순서로 슬롯에 들어가며 마지막 결과는 `미역숲`이다.
