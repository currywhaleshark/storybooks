# 자줏빛 리본의 손님 — 페이지 계획

기준 대본: `C:/Users/yurib/Downloads/자줏빛_리본의_손님_수정본(1).md`

제작 형식 변경:

- 기존 00 표지 + 01~14 텍스트 포함 단일 페이지 방식은 중단한다.
- 표지는 별도이며, 내지는 32페이지로 구성한다: 1p 속표지 / 2~29p 14개 그림·글 펼침 / 30p 단서 정리 / 31p 한글 놀이 / 32p 판권·시리즈 로고.
- 각 장면은 왼쪽 그림 페이지와 오른쪽 글 페이지로 나눈다. 세부 매핑은 `print_spread_plan.md`를 따른다.

공통 잠금:

- 세로형 그림책 페이지, 시리즈 기존 최종본 규격을 배치 시작 전에 다시 확인한다.
- 본문은 기준 대본의 각 `Text:` 블록을 그대로 사용한다.
- 본문 페이지에는 공식 크림색/조개빛 설명 패널 스타일을 사용한다.
- 캐릭터 얼굴, 손, 핵심 단서, 간판, 자모 카드 위에 패널을 겹치지 않는다.
- 셜록 핀·펄리·크랩슨·빵집 주인은 공식 시트를 실제 입력한다.
- 펄리의 장거리 이동 장면은 독립적으로 떠서 헤엄치게 하지 않고, 셜록 핀이 아래 조개를 한 팔로 받치고 다른 손으로 옆을 감싸 안아 운반한다. 정지 장면에서는 아래 조개 전체를 바닥·책상·받침에 접지한다.
- 모리·산호 골목 3가게·미역숲 물길·단서 소품은 승인된 공식 신규 시트를 실제 입력한다.
- 본편 전체에서 큰 실루엣·표정·핵심 단서는 선명하게 유지하되, 작은 금빛 점·점묘·잔기포·잔자갈·미세 잎맥·반복 하이라이트는 절제한다.
- 넓고 매끈한 색면과 분명한 시선 중심을 우선하며, 화면 전체를 균일한 미세 입자로 채우지 않는다. 흐림·저해상도·밋밋한 무질감으로 해결하지 않는다.
- 모든 배치 프롬프트와 페이지 QA에 `고주파 질감 억제 / 핵심 단서 선명 / 배경 미세 요소 절제`를 공통 항목으로 넣는다.
- 캐릭터는 공식 시트의 2D 선화·애니메이션풍 큰 눈·제한된 부드러운 명암을 유지한다. 3D 토이·클레이·픽사풍 구형 마스코트, 과도한 광택과 입체 음영을 금지한다.
- 공식 캐릭터가 아닌 단역도 같은 2D 선화 스타일로 단순화하며, 새로운 고광택 마스코트 디자인을 만들지 않는다.

## 배치별 핵심 QA

### 배치 1 — 01~04

- 세 가게의 좌우 순서와 외형을 한 번 정한 뒤 모든 페이지에서 유지한다.
- 잘못 걸린 간판 상태와 03페이지 원형 화살표가 같은 규칙을 가리켜야 한다.
- 04페이지 리본은 모리 머리 리본의 재질·색·금빛 테두리와 일치해야 한다.

### 배치 2 — 05~07

- 카드의 테두리 세 묶음과 글자 순서를 실제 소품 시트와 대조한다.
- 생성 한글이 틀리면 장면 전체를 버리지 않고 카드/텍스트만 최소 교정한다.
- 07페이지는 정확한 글자 조립이 최우선이며 장식이 글자를 가리면 실패다.

### 배치 3 — 08~10

- 08의 물길 구조를 09·10 배경에서도 같은 장소로 읽히게 유지한다.
- 모리의 리본, 포니테일 높이, 망토 길이, 조끼, 시계 사슬, 꼬리색을 공식 시트와 대조한다.
- 셜록 핀과 모리를 비슷한 시각적 비중으로 배치한다.

### 배치 4 — 11~12

- 물살 방향, 모리의 몸 기울기, 미역이 갈라지는 방향을 한 동작으로 연결한다.
- 12페이지에서 모리는 겁먹거나 쫓겨 달아나는 표정이 아니라 계획대로 떠나는 여유를 유지한다.
- 물살 뒤 셜록 핀 손에 남는 것은 소용돌이 카드 한 장뿐이다.

### 배치 5 — 13~14

- 13페이지의 가게 위치는 01과 동일하며 간판만 정상 상태다.
- 14페이지에 다른 에피소드 소품이 섞이지 않게 한다.

### 배치 6 — 00

- 승인된 09~12페이지의 모리 외형과 미역숲 색감을 재사용한다.
- 제목을 정확히 `심해탐정 셜록 핀 / 자줏빛 리본의 손님`으로 렌더링한다.
- 표지는 핵심 수수께끼를 암시하되 자모 해답 `미역숲`은 직접 공개하지 않는다.
