## 공통 잠금

- 밝고 따뜻한 딥블루·보라 사무소, 골드 물방울 램프, 조개 책상과 의자, 단서 칠판, 둥근 조개·산호 장식.
- 셜록 핀과 펄리는 공식 시트의 얼굴·색·의상·신체 구조를 유지한다. 추가 팔다리 금지.
- 우체부는 성인 주황-금색 해마, 청록 모자와 지느러미를 유지한다.
- 우체부의 몸에는 앞·옆·뒤로 이어지는 닫힌 크림색 사선 어깨끈 띠가 있다. 파손 상태에서는 몸통 띠가 유지되고, 허리에서 아래로 내려오는 짧은 천 연결 탭의 끝만 거칠게 뜯어져 있다. 황동 고리와 가방은 없다.
- 본문 페이지는 밝은 크림색 둥근 패널, 얇은 점선 테두리, 넉넉한 안쪽 여백을 사용한다.
- 요청한 한글 외에는 읽을 수 있는 간판·카드·가짜 글자를 넣지 않는다.
- 조개시계 모퉁이, 산호에 걸린 가방, 황동 고리는 00~03의 장면 삽화에 직접 보여 주지 않는다.
- 다른 에피소드의 꽃게, 별진주, 종이 더미, 문틈, 음악 기호를 가져오지 않는다.

## 00 표지

### 장면

탐정 사무소 내부 와이드 표지. 화면 위쪽 35~40%는 제목을 위한 어두운 청색 여백. 아래쪽에 셜록 핀이 의자에 앉아 우체부를 바라보며 모자를 살짝 들고, 펄리는 옆에서 놀란다. 문가의 우체부는 전신이 보이며 가방 없이 뜯긴 어깨끈만 남아 있다. 한쪽에 그림 없는 작은 물음표 카드 세 장이 물방울 안에 떠 있다. 정답 장소나 가방은 보이지 않는다.

### 실제 입력 레퍼런스

셜록 핀, 펄리, 사무소, 우체부 외형, 어깨끈 착용 구조, 우편가방 연결 구조, 최근 승인 표지.

### 정확한 텍스트

```text
심해탐정 셜록 핀

가방끈이 말해 준 것
```

## 01

### 장면

포근한 오후의 같은 사무소. 셜록 핀과 펄리가 책상에 마주 앉아 미역 쿠키를 먹고 이야기한다. 조개 테두리 크림색 접시에 짙고 연한 초록색 별·조개 모양 비스킷만 사용한다. 창밖은 평화로운 산호 골목. 벽 지도에는 여러 랜드마크 중 푸른 조개시계와 빨간 소용돌이 산호가 나란히 있는 작은 모퉁이 그림 하나가 있으나 가방·고리·사건 표시는 없다. 왼쪽 아래에 크림색 텍스트 패널.

### 실제 입력 레퍼런스

셜록 핀, 펄리, 사무소, 텍스트 패널, 조개시계 모퉁이, 미역 쿠키.

### 정확한 텍스트

```text
포근한 오후예요.

셜록 핀과 펄리는
탐정 사무소에서
도란도란 이야기를 나누고 있었어요.

“요즘은 사건이 없네요.”

“그러게. 딥시티가
평화롭다는 뜻이지!”

바로 그때였어요.
```

## 02

### 장면

사무소 문이 벌컥 열리고 우체부가 헐레벌떡 들어오는 전신 등장 샷. 우체부는 다급하고 걱정스럽지만 무섭지 않다. 한 손은 허전한 옆구리를 만진다. 가방은 없다. 몸을 앞·옆·뒤로 감싸는 크림색 띠와 허리에서 아래로 내려오는 뜯긴 짧은 연결 탭이 보인다. 끈 끝은 화면 앞쪽으로 향하며 큼직한 푸른 조개칠 조각 하나와 빨간 산호 섬유 몇 가닥이 붙어 있다. 황동 고리는 없다. 오른쪽 위 크림색 텍스트 패널.

### 실제 입력 레퍼런스

사무소, 텍스트 패널, 우체부 외형, 어깨끈 착용 구조, 우편가방 연결 구조, 생성된 01페이지 후보를 공간 연속성 보조로 사용.

### 정확한 텍스트

```text
벌컥!

문이 열리고
해마 우체부가
헐레벌떡 들어왔어요.

지난번 사건 때
도와주었던 그 우체부예요.

“셜록 핀, 큰일났어요!
저, 저—”

우체부가 막
말을 꺼내려는데,
```

## 03

### 장면

같은 사무소의 중간샷. 셜록 핀은 의자에서 우체부를 위아래로 차분히 살핀 뒤 한 손으로 모자 챙을 살짝 든다. 우체부는 가방 없이 뜯긴 끈만 맨 채 입을 벌리고 굳는다. 펄리는 미역 쿠키 하나를 든 채 눈이 동그래진다. 조개시계·빨간 산호·가방은 실제 장면에 등장하지 않는다. 왼쪽 아래 크림색 텍스트 패널.

### 실제 입력 레퍼런스

셜록 핀, 펄리, 사무소, 텍스트 패널, 우체부 외형, 어깨끈 착용 구조, 우편가방 연결 구조, 생성된 01·02페이지 후보를 연속성 보조로 사용.

### 정확한 텍스트

```text
셜록 핀이
우체부를 위에서 아래까지
찬찬히 바라보았어요.

그리고 먼저 말했어요.

“안녕하세요, 우체부님.

잃어버린 가방은
푸른 조개시계 아래,
빨간 소용돌이 산호에
걸려 있을 거예요.”

“네······?”

우체부의 입이
떡 벌어졌어요.
```

## QA

- 00: 제목 정확성, 셜록 핀의 주인공성, 세 물음표 카드, 정답·가방 스포일러 없음.
- 01: 쿠키 트레이만 도서관 레퍼런스에서 가져옴, 지도 랜드마크의 공정한 사전 노출, 가방·사건 표시 없음.
- 02: 우체부 전신, 닫힌 몸통 띠, 뜯긴 짧은 연결 탭, 푸른 조각+빨간 섬유, 황동 고리 없음, 허전한 옆구리를 만지는 손.
- 03: 셜록 핀의 여유, 우체부와 펄리의 놀람, 실제 정답 장소나 가방 미등장.
- 전 페이지: 정확한 한글, 캐릭터 외형, A5 세로, 크림색 텍스트 패널, 다른 에피소드 오염 없음.
