# 『심해탐정 셜록 핀』 그림책 대본 작성방법

이 문서는 『심해탐정 셜록 핀』 에피소드를 Markdown 그림책 대본으로 작성할 때 따르는 기준서이다. 사건 생성 규칙서에서 만든 사건을 실제 페이지 원고와 이미지 제작용 장면 설명으로 옮기는 방법을 정리한다.

핵심은 “이야기 원고”와 “이미지 제작 지시”를 한 파일 안에서 함께 관리하는 것이다. 각 페이지는 그림으로 무엇을 보여줄지 먼저 정하고, 그 장면 위에 들어갈 짧고 읽기 쉬운 유아용 문장을 붙인다.

---

## 1. 작성 순서

그림책 대본은 반드시 아래 순서로 만든다.

1. 사건 설계 정리
2. 공통 스타일 규칙 정리
3. 고정 캐릭터 설정 정리
4. 페이지 흐름 설계
5. 각 페이지 장면 설명 작성
6. 각 페이지 Text 작성
7. 품질 검사

사건 설계 없이 바로 페이지 문장을 쓰지 않는다. 셜록 핀 시리즈는 추리 구조가 핵심이므로, 진상과 단서가 먼저 탄탄해야 페이지 원고도 자연스럽다.

---

## 2. 파일 위치와 이름

에피소드 대본은 아래 위치에 저장한다.

```text
series/sherlock-fin-deep-city/docs/episodes/
```

파일명은 에피소드 제목을 한글 그대로 쓰되, 띄어쓰기는 밑줄로 바꾼다.

예시:

```text
세_조각_초대장.md
밤마다_반짝이는_창문_무늬.md
버블_가로등이_깜빡깜빡.md
```

이미지 폴더는 대본 안에 함께 적는다.

```text
series/sherlock-fin-deep-city/images/episodes/에피소드_제목
```

## 4. 사건 설계 작성법

### 4-1. 사건 유형

사건 유형은 사건 생성 규칙서의 유형을 사용한다.

가능한 유형:

- 분실 / 이동형
- 현상 / 원인형
- 혼선 / 착각형
- 감정 / 오해형
- 친구 찾기 / 길 잃음형
- 암호 / 기호 해독형
- 말 조각 이어맞추기형
- 소리 맞히기형
- 그림자 / 실루엣 맞추기형
- 표정 / 마음 읽기형

여러 유형이 섞이면 함께 적는다.

예시:

```markdown
말 조각 이어맞추기형 / 혼선·착각형
```

### 4-2. 진상

진상은 실제로 일어난 일을 먼저 적는다. 악의, 범죄, 거짓말, 처벌 중심이 되면 안 된다.

좋은 진상:

```text
크랩슨은 친구들에게 “세 시에 재즈 광장에서 함께 춤추자!”라고 초대했다.
그런데 버블 분수 소리와 친구들의 위치 때문에 친구들은 각각 말의 일부만 들었다.
```

### 4-3. 표면 사건

표면 사건은 친구들에게 어떻게 문제처럼 보였는지 적는다.

예시:

```text
파티 시간이 되었는데 친구들이 서로 다른 곳으로 가거나,
서로 다른 말을 기억해서 재즈 광장에 모이지 못한다.
```

### 4-4. 단서 3개

단서는 반드시 진상에서 자연스럽게 나온다. 각 단서는 서로 다른 정보를 주어야 한다.

예시:

```markdown
### 단서 1

펄리는 “광장”이라는 말만 들었다.  
의미: 약속 장소와 관련된 말 조각이다.

### 단서 2

팝팝은 “세 시”라는 말만 들었다.  
의미: 약속 시간과 관련된 말 조각이다.

### 단서 3

모모는 “춤추자”라는 말만 들었다.  
의미: 약속에서 함께 하려던 행동과 관련된 말 조각이다.
```

### 4-5. 소리 단서 주의

현재 일어나고 있는 사건이면 셜록 핀이 직접 소리를 들을 수 있다.

이미 일어난 사건이면 소리 단서는 직접 청취가 아니라 증언이나 남은 소리 흔적으로 처리한다.

좋은 예:

```text
모모가 “아까 딱 하는 소리를 들었어”라고 말한다.
```

나쁜 예:

```text
사건은 밤에 끝났는데, 아침에 온 셜록 핀이 밤의 소리를 직접 듣는다.
```

## 5. 공통 스타일 규칙 작성법

공통 스타일 규칙은 이미지 생성과 장면 일관성을 위한 기준이다. 매 에피소드마다 길게 새로 만들기보다, 시리즈 공통 문장을 기본으로 두고 해당 에피소드의 장소와 정서를 조금 더한다.

반드시 포함할 내용:

- 3세 대상 유아 그림책
- 밝고 따뜻한 네온 재즈 해저도시 딥시티
- 무섭지 않은 심해
- 산호초 건물, 조개 문, 버블 가로등, 물방울 조명
- 깊은 파랑, 보라, 에메랄드, 핑크, 골드 색감
- 둥글고 귀여운 캐릭터
- 감정이 한눈에 읽히는 표정
- 텍스트가 들어갈 여백
- 페이지마다 구도와 시점 반복 금지

## 6. 고정 캐릭터 설정 작성법

등장하는 캐릭터만 적는다. 모든 시리즈 캐릭터를 매번 전부 적을 필요는 없다.

각 캐릭터는 한 줄 안에 아래 정보를 담는다.

```text
이름: 외형 핵심, 소품, 성격, 이번 이야기에서의 역할.
```

예시:

```markdown
- 셜록 핀: 청록색 머리의 어린 인어 탐정. 탐정 모자, 갈색 탐정 코트, 노란 돋보기. 밝고 자신감 있으며, 먼저 보고 듣고 생각한다.
- 펄리: 분홍색 조개껍데기 안에 사는 아기 조개. 큰 눈, 작은 볼, 나비넥타이, 분홍색 별진주. 감정이 얼굴에 잘 드러난다.
```

신규 캐릭터가 있으면 “신규 캐릭터”임을 명시하고, 이후 이미지 레퍼런스가 필요할 수 있음을 적어도 좋다.

## 7. 페이지 구성 원칙

### 7-1. 권장 페이지 수

기본은 표지 포함 11~12장면이다.

```text
00 표지
01 도입
02 사건 발생 또는 말/행동의 원인
03 표면 사건 확인
04 셜록 핀에게 의뢰
05 단서 1
06 단서 2
07 단서 3
08 단서 연결
09 진상 확인
10 회복과 약속
11 마무리 또는 시리즈 반복 문장
```

10페이지 안팎으로 줄일 때는 `04 의뢰`와 `05 단서 1`을 합치거나, `11 마무리`를 `10`에 합친다.

### 7-2. 페이지마다 해야 할 일

각 페이지는 반드시 하나의 명확한 기능을 가진다.

좋은 페이지 기능:

- 배경 소개
- 사건 발생
- 친구의 감정 보여주기
- 셜록 핀이 듣기
- 단서 발견
- 단서 연결
- 진상 확인
- 사과와 고마움
- 새 약속
- 따뜻한 놀이 마무리

한 페이지에 사건, 단서, 추리, 해결을 모두 넣지 않는다.

## 8. 페이지 장면 설명 작성법

각 페이지 제목 아래에는 먼저 이미지 제작용 장면 설명을 쓴다.

장면 설명에는 아래 요소를 포함한다.

- 장소
- 등장 캐릭터
- 각 캐릭터의 행동
- 핵심 감정
- 화면 구도
- 텍스트 여백 위치
- 중요한 단서가 있다면 그 단서의 시각적 위치

예시:

```markdown
### 05

펄리가 조개 간식 가게 앞에서 기다리고 있다. 펄리는 작은 별진주를 꼭 안고, 재즈 광장이 아닌 산호 골목 쪽을 바라본다. 셜록 핀과 크랩슨이 다가와 부드럽게 묻는다. 핵심은 첫 번째 말 조각 “광장”. 구도는 펄리 중심의 가까운 중간샷. 텍스트 여백은 오른쪽 위.

Text:
“먼저 펄리에게 물어보았어요.
...”
```

### 8-1. 구도 반복 금지

연속 페이지가 모두 같은 중간샷이면 지루하다. 아래를 섞는다.

- 넓은 도입 전경
- 중간샷
- 가까운 표정 클로즈업
- 단서 확대
- 위에서 보는 지도식 장면
- 추리 칠판 정면 장면
- 마지막 축제 전경

## 9. Text 작성법

### 9-1. 문장 길이

대상은 만 3세 전후이므로 문장은 짧게 쓴다.

권장:

- 한 줄은 짧게
- 한 문단은 2~4줄
- 한 페이지 Text는 4~8개의 짧은 문장
- 대사는 한 번에 길지 않게

### 9-2. 문장 톤

문장은 부드럽고 반복감 있게 쓴다.

좋은 문장:

```text
먼저 잘 들어 보자.
단서를 하나로 모아 보자.
아, 그런 이유가 있었구나!
```

피할 문장:

```text
범인을 찾아야 해.
네가 그랬지?
거짓말하면 안 돼.
벌을 받아야 해.
```

### 9-3. Text 표기 방식

각 페이지의 본문은 반드시 `Text:` 아래에 큰따옴표로 묶어 적는다.

```markdown
Text:
“딥시티에
반짝반짝 오후가 왔어요.

재즈 광장에서는
작은 파티 준비가 한창이었지요.”
```

## 10. 추리 장면 작성법

추리 장면은 단서 3개가 시각적으로 하나로 모이는 장면이어야 한다.

권장 장치:

- 추리 칠판
- 말풍선 카드
- 물방울 카드
- 돋보기 확대
- 연결선
- 생각 거품

추리 문장은 아래 구조를 따른다.

```text
단서 1은 ○○을 알려준다.
단서 2는 △△을 알려준다.
단서 3은 □□을 알려준다.
세 단서를 함께 보면 진상은 이것이다.
```

유아가 이해할 수 있도록 추리의 결론은 한 문장으로 짧게 정리한다.

## 11. 해결 장면 작성법

해결은 처벌이 아니라 회복이다.

반드시 포함할 요소:

- 친구의 사정을 듣는다.
- 오해가 풀린다.
- 필요하면 미안하다고 말한다.
- 필요하면 고맙다고 말한다.
- 다음 행동을 약속한다.
- 마지막은 함께 놀이하거나 밝은 장면으로 끝난다.

마지막에 너무 교훈적으로 설명하지 않는다. 셜록 핀의 짧은 말이나 친구들의 반복 문장으로 닫는다.

좋은 마무리:

```text
잘 보고,
잘 듣고,
잘 생각하면
친구의 마음도 찾을 수 있어!
```

## 12. 품질 검사

대본 작성 후 아래 항목을 모두 확인한다.

### 사건 검사

- [ ] 진상이 먼저 정해져 있는가?
- [ ] 표면 사건은 진상에서 자연스럽게 생겼는가?
- [ ] 사건이 무섭거나 악의적이지 않은가?
- [ ] 단서 3개가 서로 다른 정보를 주는가?
- [ ] 세 단서를 합치면 결론이 자연스럽게 나오는가?
- [ ] 소리 단서는 사건 시점에 맞게 직접 청취, 증언, 남은 소리 흔적으로 처리했는가?

### 페이지 검사

- [ ] 표지와 본문 페이지가 구분되어 있는가?
- [ ] 각 페이지에 장면 설명과 Text가 있는가?
- [ ] 한 페이지에 기능이 너무 많이 들어가지 않았는가?
- [ ] 페이지마다 구도와 시점이 반복되지 않는가?
- [ ] 텍스트 여백 위치가 적혀 있는가?
- [ ] 중요한 단서가 그림으로 보이도록 설명되어 있는가?

### 문장 검사

- [ ] 문장이 만 3세 전후 아이에게 너무 길지 않은가?
- [ ] 무서운 표현, 추궁하는 표현, 처벌 표현이 없는가?
- [ ] “잘 보고, 잘 듣고, 잘 생각하기”가 자연스럽게 드러나는가?
- [ ] 친구의 말을 들어보고 오해를 푸는 과정이 있는가?
- [ ] 마지막이 따뜻하고 안전하게 끝나는가?
